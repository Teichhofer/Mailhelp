# Mailhelp-Logo

`logo.png` ist das vom Nutzer bereitgestellte offizielle Anwendungslogo.
Die Originaldatei wurde unverändert übernommen.

Verwendung: Repository-Startseite, Einrichtungsanleitung und Telegram-Botprofil.
Die Datei wird als Paketressource mitgeliefert und kann über
`importlib.resources.files("mailhelp").joinpath("assets", "logo.png")`
gefunden werden. Damit steht sie auch installierten Anwendungen und dem
Docker-Image zur Verfügung.
