# Mailhelp 3.8 – Web-Lernmodus und Betrieb

**Arbeitsstand:** 3.8.28, 4. November 2026. Vollständig umgesetzt; Gesamtabnahme bestanden ([Bericht](Release-3.8.md)).

Dieser Teilplan macht die im [Gesamtfahrplan 4.0](Planung-4.0.md) ausdrücklich
festgelegte Entwicklungslinie 3.8.x sichtbar. Er umfasst die Schritte 4.1–4.12,
5.1–5.8 und 8.1–8.7. Die gesonderte Veröffentlichung 4.0.0 aus Schritt 8.8 ist
nicht Teil einer Veröffentlichung von 3.8.

| Schritte | Patch-Zuordnung | Umsetzung |
| :--- | :--- | :--- |
| 4.1–4.5 | 3.8.0–3.8.4 | Gemeinsamer Lernkern, versionierter Job, Hintergrundausführung, Pause/Abbruch und Kostenreservierung |
| 4.6–4.10 | 3.8.5–3.8.9 | Start, Fortschritt, Themenkarten, Ausschlüsse/Absender und Ordnerreview |
| 4.11–4.12 | 3.8.10–3.8.11 | Wiederherstellbare gemeinsame Übernahme und Browserdurchlauf |
| 5.1–5.6 | 3.8.12–3.8.17 | Sichere Laufzeitgenerationen und bestätigtes Neuladen |
| 5.7–5.8 | 3.8.18–3.8.19 | Lesender Selbsttest, Monatskosten und Abfragezeiten |
| 8.1–8.5 | 3.8.20–3.8.24 | Gemeinsame Anbietermatrix und begründete Operationsgrenzen |
| 8.6–8.7 | 3.8.25–3.8.26 | Windows/Linux/Docker, CI und Abschlussbericht |

Die Patch-Zuordnung bündelt den lokalen Arbeitsstand; sie behauptet keine einzeln
veröffentlichten Zwischenreleases. Die Abnahme und konkreten Betriebsgrenzen stehen
im [Releasebericht 3.8](Release-3.8.md).
