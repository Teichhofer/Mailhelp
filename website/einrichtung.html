Loslegen

Mailhelp einrichten.

Die Software läuft in deiner Umgebung. Verbinde deine IMAP-Postfächer, den gewählten KI-Dienst sowie Kalender- und Aufgabenziele. Du bedienst Mailhelp per Telegram oder über die authentifizierte Weboberfläche.

1. Voraussetzungen vorbereiten

  • Python 3.12.x für lokale Installation oder Docker für Linux.
  • IMAP-Zugang zu einem Postfach, das du verwenden darfst.
  • Optional: Elternkonto der Schule in IServ für Elternbriefe.
  • Zugänge zum gewählten KI-, Kalender- und Aufgabendienst; Google und Microsoft benötigen OAuth.
  • Für Telegram einen eigenen Bot, für die Weboberfläche einen lokalen Sitzungsschlüssel.

2. Lokal unter Windows installieren

git clone https://github.com/Teichhofer/Mailhelp.git
cd Mailhelp
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.lock
.venv\Scripts\python -m pip install --no-deps -e .
Copy-Item config.example.yaml config.yaml
Copy-Item .env.example .env
Copy-Item irrelevant-senders.example.json irrelevant-senders.json

Trage persönliche Zugänge in .env oder die Prozessumgebung ein; bei laufender Weboberfläche geht das auch unter Einstellungen → Zugangsdaten, wo gespeicherte Werte nie angezeigt werden. Passe Ziele und Einstellungen in config.yaml an. Die Vorlage enthält ausschließlich Beispieldaten.

3. Erst prüfen, dann verbinden

.venv\Scripts\mailhelp --check

Dieser Aufruf validiert die Konfiguration ohne Netzwerkzugriff. Der optionale Aufruf mailhelp --check-access prüft Dienste und sendet bei aktiviertem Telegram eine Testnachricht; er erstellt keine Aufgaben oder Termine.

4. Betrieb starten

.venv\Scripts\mailhelp

Prüfe die Vorschläge im konfigurierten Telegram-Chat oder in der authentifizierten Weboberfläche. Eine Bestätigung ist versionsbezogen und gilt für den jeweils angezeigten Vorschlag.

Testmodus und Kalender

test_mode simuliert Aufgaben und Kalendertermine. Dabei erfolgen keine Zugriffe auf die simulierten Kalender- und Aufgabendienste; IMAP, LLM und gegebenenfalls Telegram bleiben online. Ausdrücklich gestartete Zugangstests und das Speichern eines Antwortentwurfs sind davon getrennte Vorgänge. Für Modellvergleiche ohne Schreibdienste ist --decision-test vorgesehen.

Weboberfläche und Zielprofile

Setze web.enabled: true und hinterlege MAILHELP_WEB_SECRET mit mindestens 32 Zeichen. Öffne nach dem Start http://127.0.0.1:8765. Ein zweiter Terminalaufruf mit mailhelp --pair erzeugt den Einmalcode. Mit telegram.enabled: false läuft die Anwendung ohne Telegram.

Google wird am Host mit mailhelp --google-auth, Microsoft mit mailhelp --microsoft-login angemeldet. --profile 2 richtet ein zusätzliches Zielprofil ein. OAuth-Tokens bleiben außerhalb des Browsers in der lokalen Umgebung; Passwörter und API-Schlüssel lassen sich unter Einstellungen → Zugangsdaten nur schreibend eintragen.

IServ-Elternbriefe

Unter Einstellungen → IServ-Konten die Adresse der Schule und das Postfach für Zielprofil und Standards eintragen, unter Zugangsdaten die Anmeldung des Elternkontos hinterlegen, mit der Diagnose „iserv“ prüfen und den Entwurf übernehmen. Elternbriefe werden samt Anhängen wie Mails verarbeitet und gelten immer als relevant; in IServ wird nichts bestätigt oder verändert.

Docker und Google OAuth

Die ausführliche Anleitung enthält die Compose-Dateien, beschreibbare Verzeichnisse, Google-OAuth-Einrichtung und Verfahren bei abgelaufenen Berechtigungen.
