Loslegen

Mailhelp einrichten.

Die Software läuft in deiner Umgebung. Für den Standardbetrieb verbindest du ein Postfach, OpenRouter, Telegram, Todoist und Google Kalender.

1. Voraussetzungen vorbereiten

  • Python 3.12.x für lokale Installation oder Docker für Linux.
  • IMAP-Zugang zu einem Postfach, das du verwenden darfst.
  • API-Zugänge und einen eigenen Telegram-Bot; Google Kalender benötigt OAuth.

2. Lokal unter Windows installieren

git clone https://github.com/Teichhofer/Mailhelp.git
cd Mailhelp
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -e ".[test]"
Copy-Item config.example.yaml config.yaml
Copy-Item .env.example .env

Trage persönliche Zugänge in .env oder die Prozessumgebung ein. Passe Ziele und Einstellungen in config.yaml an. Die Vorlage enthält ausschließlich Beispieldaten.

3. Erst prüfen, dann verbinden

.venv\Scripts\mailhelp --check

Dieser Aufruf validiert die Konfiguration ohne Netzwerkzugriff. Der optionale Aufruf mailhelp --check-access prüft Dienste und sendet eine Telegram-Testnachricht; er erstellt keine Aufgaben oder Termine.

4. Betrieb starten

.venv\Scripts\mailhelp

Prüfe die Vorschläge im konfigurierten Telegram-Chat. Eine Bestätigung ist versionsbezogen und gilt für den jeweils angezeigten Vorschlag.

Testmodus und Kalender

test_mode simuliert nur Todoist-Schreibzugriffe. Bestätigte Kalendertermine können auch in diesem Modus tatsächlich angelegt werden. Für Modellvergleiche ohne Schreibdienste ist --decision-test vorgesehen.

Docker und Google OAuth

Die ausführliche Anleitung enthält die Compose-Dateien, beschreibbare Verzeichnisse, Google-OAuth-Einrichtung und Verfahren bei abgelaufenen Berechtigungen.
